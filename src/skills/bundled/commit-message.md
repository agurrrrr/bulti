# 커밋 메시지 규약

커밋 메시지를 작성할 때 아래 규약을 따른다.

## 형식

```
<타입>(<범위>): <요약>

<본문>
```

## 타입

| 타입 | 의미 |
|------|------|
| feat   | 새 기능 |
| fix    | 버그 수정 |
| refactor | 리팩터링 (동작 변화 없음) |
| docs   | 문서 변경 |
| test   | 테스트 추가·수정 |
| chore  | 빌드·도구·관리 작업 |

## 규칙

1. 요약은 50자 이내, 명령형으로 작성한다.
2. 본문은 "왜"를 설명하고, 선택 사항으로 "무엇을" 포함한다.
3. 범위에는 모듈 이름을 넣는다 (예: `feat(skills): ...`).

## 예시

> feat(skills): 스킬 레이지 로딩 구현
>
> 프로젝트 → 글로벌 → 번들 순으로 스킬을 발견하고,
> 시스템 프롬프트에는 인덱스만 주입하며 skill_load 도구로 본문을 로드한다.

# 한국어 보고 스타일

사용자에게 보고할 때 아래 규칙을 따른다.

## 규칙

1. **존댓말 사용**: 모든 보고는 "-습니다/-니다" 형식의 존댓말로 작성한다.
2. **완성 문장**: 조사와 어미를 생략하지 않고 의미가 명확한 완전한 문장을 쓴다.
   - 금지: 전보체("완료함", "확인함"), 비유적 어휘 치환, 조사 탈락.
   - 예: "모든 작업이 완료되었습니다. 최종 결과는 다음과 같습니다."
3. **구조화**: 결론 → 근거 → 세부 내역 순으로 정리한다.
4. **검증 결과 포함**: 코드 변경 후에는 빌드·테스트 검증 결과를 반드시 보고한다.

## 예시

> 단계 8(스킬 시스템) 구현을 완료했습니다. 발견 순서·frontmatter 파싱·skill_load 도구 테스트를 모두 통과했으며, CLI list/show도 정상 동작합니다.
